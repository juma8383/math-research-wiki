# Cycle 27 (absolute Cycle 27, seventh-loop C2) — direct attack on (A): the CAPP-weakened Williams template IS productive for easy-SAT classes, but the resulting LB does NOT reach (A) (non-explicit, subexp, off-window); the construction lock is LOCALIZED to the bridge between two corners

## Framing (carried from Cycle 22)

The sixth-loop C2 ([s1a-class-is-dnf-easy-sat]) located the structural obstruction for the FP^NP route as the full balanced point (A), and noted the S1.a class (DNF / depth-d AND_{d−1}/OR_d formulas) has EASY SAT, so the Williams **faster-SAT** template gives only trivial LBs (parity, 2^{n-1}). Cycle 21 ([fpnp-converges-to-williams-template]) framed the FP^NP route as "an E^NP LB for the balanced-point class, attainable via a faster-SAT/CAPP algorithm for that class — the Williams template." The genuinely-open methodological question, the exact door between "meta obstruction removed" (Cycle 21) and "structural obstruction solved," is: **is there a non-faster-SAT (e.g. a CAPP-weakened Williams-template) route to an E^NP / EXP circuit lower bound for a class with EASY SAT?** This cycle attacks that question directly.

## Four web searches (all search/arXiv-summary-level, NOT PDF-line-verified)

1. **Williams template weakening over time (SAT → Gap-UNSAT → CAPP).** Confirmed the template requirement WEAKENED historically: Williams 2010/2011 needs a faster-than-2^n **SAT** algorithm for the class; Murray-Williams 2018 (STOC / "Easy Witness Lemmas for the Circuit Model") and Chen-Ren 2020 relax to a nondeterministic **Gap-UNSAT** / approximate-counting requirement; Chen-Lyu-Williams FOCS 2020 ("Three Lower Bounds for Circuit Classes via A-Efficient Algorithms") give the cleanest form — a non-trivial **CAPP** (derandomization / approximate acceptance) for AND_4∘C at 2^{n−n^ε} suffices. The template's weakest common form: **a non-trivial CAPP for the class ⟹ an average-case E^NP lower bound against the class.**

2. **CLW FOCS 2020 Theorem 1.2 (the load-bearing template instance).** "If CAPP of AND_4∘C circuits of size S can be solved in 2^{n−n^ε} time, then there is a language in E^NP requiring 2^{Ω(n)} size C-circuits." The LB is an **average-case** E^NP LB against C, built by a **Williams-style P^NP refuter/diagonalization** (the A-efficient algorithm + easy-witness contrapositive), NOT by an explicit construction of the hard function.

3. **Deterministic CAPP for DNF / AC⁰ / depth-d (the easy-SAT classes) is known UNCONDITIONALLY.** Gopalan-Meka-Reingold CCC 2012: deterministic quasi-polynomial-time DNF/CNF approximate counting (#SAT/CAPP) in n^{O((log log n)²)} — a sub-2^n derandomization for DNF. Trevisan ECCC TR02-069: linear-time approximate counting for constant-width k-DNF. Williams 2014: #SAT/CAPP for ACC⁰ (⊇ AC⁰ ⊇ DNF) in 2^{n−n^ε} time. So the CAPP precondition of CLW Thm 1.2 is **unconditionally satisfied** for C ⊇ DNF/AC⁰/depth-d (the S1.a class and its superclasses).

4. **No result pushes such LBs to the explicit / AC⁰-constructible / tight-window regime (A).** The LB machinery surveyed: (a) Chen-Li-Liang ECCC TR24-182 (2024) — near-maximum 2^n/n LB for AMEXP-with-advice, a STRONG class (E with advice), not AC⁰-constructible, not at the Lupanov tight window; (b) Chen-Williams-Yang ITCS 2023 ([cwy-2023-blackbox], already in the wiki) — black-box constructivity is UNAVOIDABLE for NEXP LBs, and **deterministic polylog(N)-constructive properties useful against AC⁰ are impossible** unconditionally (Thm 1.6) — the meta-reason a Williams/CAPP-template LB cannot be made deterministic-explicit against AC⁰; (c) Carmosino-Dang-Jackman 2026 — gate-elimination refuters give LINEAR explicit LBs (Li-Yang STOC'22 affine dispersers: 3.1n), built by a P refuter against general circuits — explicit but linear and against general circuits, not AC⁰-constructible, not tight-window; (d) Bhattacharya-Chattopadhyay ECCC TR25-106 (2025) — super-poly Res(⊕) LBs via Tseitin-on-expanders LIFTED with **IP gadgets** (the lifting framework = S1.a's gadget family) that have small correlation with all parities — the lifting machinery (S1.a's gadget family) yields genuine LBs in PROOF COMPLEXITY (Res(⊕)), not circuits, re-confirming [proof-complexity-face-barriered] and the descriptive-Cycle-25 convergence to the proof-complexity hub.

## Synthesis: a PARTIAL WALK-BACK of abs22, NO BREAKTHROUGH

`[capp-template-productive-for-easy-sat]` `[cycle22-sat-vs-capp-conflation]`: Cycle 22's "the Williams template is trivial for S1.a" is CORRECT only for the **faster-SAT** version. The CAPP-weakened Williams template (Murray-Williams 2018, Chen-Ren 2020, CLW FOCS 2020 Thm 1.2) IS productive for easy-SAT classes: combining CLW Thm 1.2 (CAPP for AND_4∘C ⟹ average-case E^NP LB against C) with the unconditional deterministic CAPP for DNF/AC⁰/depth-d (GMR 2012, Trevisan 2002, Williams 2014) yields an **unconditional non-trivial average-case E^NP LB against DNF / AC⁰ / depth-d** — the S1.a class and its superclasses — via CAPP, NOT via faster-SAT. So a non-(faster-SAT) Williams-template route to an E^NP LB for an easy-SAT class EXISTS. This walks back the strong reading of abs22 ([williams-template-convergence-asymmetric]): the Williams template is NOT globally unproductive for S1.a; only the faster-SAT engine is. The CAPP engine produces a genuine, unconditional, non-trivial LB against the balanced-point class.

`[clw-lb-non-explicit-refuter]` `[clw-lb-subexp-not-tight-window]`: BUT this LB does NOT reach (A), on three independent axes.
- **(i) NON-EXPLICIT.** The CLW LB is built by a **P^NP refuter/diagonalization** (Williams-style easy-witness contrapositive + the A-efficient CAPP algorithm), not by the AC⁰-constructible lifting witness g that (A) requires. The hard function it certifies is "the refuter's diagonalization output," existentially specified, not an explicit constructible g at the balanced point. This is the [single-lb-implies-class-lb] / [vicinity-does-not-retighten] gap (Cycle 4/6) made concrete: a class LB EXISTING ≠ the reduction's specific witness g being constructed.
- **(ii) SUBEXPONENTIAL SIZE.** The LB is of the form "requires 2^{n^ε}-size C-circuits" — a SUBEXPONENTIAL (2^{n^ε}) size bound — NOT the tight lifting window [(1−4δ)t·n², (1+4δ)t·n²] = 2^{Θ(n)} that (A) must pin (the [s1a-antiprox-obstruction] tight window). The CAPP-template's resolution is at the 2^{n−n^ε} CAPP scale, which translates to a 2^{n^ε} LB, qualitatively coarser than the tight Θ(n)-exponent window.
- **(iii) OFF the balanced point.** An E^NP LB yields the EXPENSIVE/existence side (a function as hard as parity, [structural-obstruction-is-full-balanced-point]); the CLW LB is no exception — it does NOT provide the small-gap (Lupanov-structure) side, the non-compositional half of (A) ([balanced-point-non-compositional]).

`[construction-lock-localized-two-corners]`: the construction lock is now LOCALIZED with precision.
