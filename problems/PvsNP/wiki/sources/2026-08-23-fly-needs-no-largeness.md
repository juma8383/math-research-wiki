## Finding 1 — FLY's "black-box natural property" requires SOUNDNESS-ON-RANDOM, NOT largeness `[fly-needs-no-largeness]` `[fly-soundness-on-random]`

The web-verified FLY definition (Fan-Li-Yang STOC 2022, "The Exact Complexity of Pseudorandom Functions and the Black-Box Natural Proof Barrier for Bootstrapping Results"):

> A property P is *black-box natural* against circuit class Λ if:
> - **Black-box constructivity:** There exists a PPT oracle algorithm A such that for f ∈ P_yes, Pr[A^f(1^n)=1] ≥ 2/3, and **for random g, Pr[A^g(1^n)=1] ≤ 1/3**.
> - **Usefulness:** For every language in Λ, f_n ∈ P_no for infinitely many n.

**The "for random g, Pr[A^g=1] ≤ 1/3" condition is SOUNDNESS-ON-RANDOM** — the distinguisher does NOT fire on random functions; it fires only on the SPECIFIC hard functions (P_yes). This is the PRF-breaker shape (distinguish a specific function family from random), NOT the RR natural-proof shape (which requires the property to be LARGE — a random function IS in the property with high probability).

**`[fly-needs-no-largeness]`: FLY's barrier does NOT require largeness. It requires the OPPOSITE — soundness-on-random (the accepted set P_yes is a MINORITY of random functions, accept ≤ 1/3).** Compare: Razborov-Rudich requires (constructivity ∧ LARGENESS ∧ usefulness), where largeness = a random function satisfies the property with high probability (the property is dense). FLY replaces RR's LARGENESS with SOUNDNESS-ON-RANDOM (= non-largeness = the accepted set is a minority). So FLY is the LARGENESS-FREE natural-proofs variant: it catches distinguishers that target SPECIFIC (non-large) hard functions — exactly the PRF-breakers that RR's largeness requirement was never about. `[honest-ceiling]`: the FLY definition is from the search-summary-level statement (the "for random g, Pr[A^g=1] ≤ 1/3" soundness condition is clearly stated in the search result), NOT PDF-line-verified — the identification of this condition as "soundness-on-random = non-largeness (the opposite of RR's largeness)" is a structural reading of the stated definition.

## Finding 2 — Dropping largeness escapes RR but lands IN FLY; the "largeness-axis escape" was illusory `[nonlargeness-not-an-fly-escape]` `[rr-and-fly-partition-by-largeness]`

The Williams LB escapes Razborov-Rudich by dropping LARGENESS (Williams' useful property is non-large — it does NOT hold for a random function w.h.p.; this is exactly `[largeness-vs-constructivity]` from Cycle 2 / Diagnosis 13). Cycle 13 framed this as a genuine (partial) escape from FLY on the "largeness axis." **Cycle 14 corrects this: the largeness-axis escape is illusory, because FLY does not require largeness — FLY requires soundness-on-random (= non-largeness). So Williams' non-large LB SATISFIES FLY's soundness condition; dropping largeness does NOT escape FLY, it makes the LB fit FLY's definition.** `[nonlargeness-not-an-fly-escape]`.

`[rr-and-fly-partition-by-largeness]`: the two natural-proofs variants PARTITION the black-box-constructive LB space by LARGENESS:
- **A LARGE black-box-constructive LB** (property holds for random w.h.p., distinguisher fires on random) is a **RAZBOROV-RUDICH** natural property — RR-blocked (RR requires largeness; PRFs rule out large natural properties).
- **A NON-LARGE black-box-constructive LB** (property holds for specific hard functions only, distinguisher sound on random = accept ≤ 1/3) is a **FAN-LI-YANG** black-box natural property — FLY-blocked (FLY requires soundness-on-random; PRFs at the threshold rule out FLY black-box natural properties).

So dropping largeness moves a black-box-constructive LB from the RR variant (large) to the FLY variant (non-large) — it escapes RR INTO FLY, not out of natural proofs. **The two barriers (RR large, FLY non-large) together cover BOTH cases: a black-box-constructive LB at the threshold is natural-proofs-blocked one way (RR, if large) or the other (FLY, if non-large).** Largeness determines WHICH variant blocks it, not WHETHER a natural-proofs variant blocks it. This is the robust synthesis: it does NOT depend on the (Cycle-13-flagged, unverified) detail of whether the CWY-constructed property specifically inherits sound-on-random — because the partition covers both the sound-on-random (non-large → FLY) and fires-on-random (large → RR) cases.

So black-box constructivity is UNAVOIDABLE for NEXP LBs — every NEXP LB yields a black-box-constructive distinguisher. There is NO NEXP LB with a non-black-box-constructive (white-box) distinguisher.

Combining CWY (NEXP LBs are unavoidably black-box-constructive) with the Cycle-14 partition (black-box-constructive LBs at the threshold are natural-proofs-blocked — RR if large, FLY if non-large):
