## What S2 set out to settle

The Route A push recorded the variant gap `[route-a-variant-gap]` as: "no MCSP variant is known NP-hard under *uniform* (logtime-uniform) AC⁰ many-one reductions." S2's task was to analyze the *most classical* reduction (Masek/AHMPS Min-DNF, and the closest known AC⁰-variant result) and decide whether the gap is a removable technicality or a fundamental barrier. The primary source **re-framed the question more sharply than the wiki had it**: Ilango (TR19-021) proved **MOCSP is NP-hard under *non-uniform* AC⁰ many-one reductions** (Corollary 4.9, ¶792, line 1377). So a meta-complexity variant *does* reach AC⁰ many-one — just non-uniformly. The precise open question is the **non-uniform → uniform (logtime-uniform) AC⁰** gap.

## The non-uniform reduction, precisely (TR19-021 §4)

- **MOCSP** (¶659, lines 1135-1138): given a truth table T, a size threshold s, and oracle functions f_1,...,f_t, decide whether there is an oracle circuit of size ≤ s computing T using f_1,...,f_t as oracles.
- **The reduction** (Theorem 4.1, ¶667-671; Corollary 4.9, ¶792-799): from r-bounded Set Cover. Fix a constant r large enough that 4-approximating r-bounded set cover is NP-hard (¶793, line 1379). For T of length m = O(n³) and a partition P=(P_1,...,P_n) of [m], the AC⁰ circuit maps an instance (c, S_1,...,S_t) to MOCSP(T, 2c; T_{S_1^P},...,T_{S_t^P}). Correctness hinges on T being **(rn)-irritable** on P.
- **(s)-irritable** (¶336-341, lines 528-538): T is (s)-irritable if for every i, removing the oracle T_{P_i} forces the oracle-circuit complexity of T above s: CC^{T_{P_1},...,T_{P_{i-1}},T_{P_{i+1}},...,T_{P_n}}(T) > s. Informally: take away any one partition piece and computing T requires size > s.
- **Existence by counting** (Lemma 4.6, ¶746-762, lines 1290-1322): a uniformly random T (length m = n³) is (rn)-irritable w.h.p. — failure ≤ n · (#oracle circuits of size rn) · 2^{−|P_i|+1} = n · 2^{Õ(rn)} · 2^{−n²+1} = 2^{−Ω(n²)} = o(1). So irritable T's are **abundant** (a random T has CC ≈ n², far above the rn = Θ(n) threshold).
- **The non-uniformity is load-bearing** (¶364-366, lines 578-580; ¶790-799, lines 1374-1389): "by **non-uniformly hardcoding** an (rn)-irritable truth table T into C, we get that 4-SetCover_r reduces to MOCSP under (non-uniform) AC⁰ many-one reductions." The T (and partition P) are **advice depending only on input length**, hardwired into the AC⁰ circuit. The rest of the map ((T,c,S_i) ↦ (T,2c; T_{S_i^P})) is genuinely AC⁰. So the **only** non-uniformity is the hardwired irritable T.
- **Checking irritability is itself MOCSP** (¶362, line 576): "we can check if a random T is (rn)-irritable using an oracle to MOCSP" — yielding the (uniform) ZPP truth-table reduction (Corollary 4.8, ¶784). This already signals that irritability is a meta-computational (circuit-lower-bound) property.

## The obstruction — uniformizing requires an explicit exponential circuit lower bound `[s2-irritable-witness-obstruction]`

To make the reduction **logtime-uniform AC⁰**, the irritable witness T (length m, a function on L := log m = O(log n) input bits) must be **explicitly constructed by a uniform-AC⁰ family** rather than hardwired as advice. The question: can a uniform-AC⁰-constructible T be (rn)-irritable?

**The threshold is exponential in L.** T is a function on L = log m = O(log n) bits (m = O(n³)). (rn)-irritability, with r = O(1) (constant, ¶793), requires CC^{except P_j}(T) > rn = Θ(n) for all j. Since oracle access only *reduces* complexity, CC^{except P_j}(T) ≤ CC(T), so **(rn)-irritability implies CC(T) > rn = Θ(n)**. And n = 2^{Θ(L)} (because L = log m ≥ log n as the partition needs m ≥ n). Therefore uniformizing requires an **explicit function T on L input bits with general-circuit complexity > 2^{Θ(L)}** — an **exponential (in L) explicit circuit lower bound.**

**Explicit constructions fall exponentially short.** The best known explicit lower bound for *general* (unrestricted) Boolean circuits on L inputs is **Θ(L)** (linear in L): Blum 1984 (3L), refined to ~5L (Find–Göös–Khot–Müller–Mukhopadhyay–Saurabh 2017+). All are linear in the input count L = Θ(log n). The required bound 2^{Θ(L)} = Θ(n) exceeds this by an **exponential factor** (Θ(n) vs Θ(log n)). No explicit function on L bits is known with general-circuit complexity 2^{Ω(L)} — this is exactly the central explicit-circuit-lower-bound problem, obstructed by the natural-proofs barrier.

`[s2-irritable-witness-obstruction]`: **the non-uniformity is load-bearing and cannot be removed for this reduction.** A random T supplies CC ≈ n² > rn (abundantly, by counting); non-uniform advice hardwires one. An *explicit uniform-AC⁰* T would need a *proven* CC > 2^{Θ(L)}, i.e., an explicit exponential general-circuit lower bound — beyond all known techniques by an exponential factor. **The non-uniform→uniform AC⁰ gap for MOCSP is exactly an explicit exponential circuit lower bound**, which is the open frontier (natural-proofs / the circuit-LB problem). This is why Ilango states the AC⁰ NP-hardness non-uniformly and leaves uniformization open (¶800-801, lines 1391-1393: "this seems difficult," citing Murray–Williams/Hitchcock–Pavan's EXP=ZPP collapse for uniform polytime).

**Robustness of the exponential threshold.** The threshold rn ≥ n (r ≥ 1) and n = 2^{Θ(L)} (since L = log m ≥ log n) are both structural: the partition needs m ≥ n, and the threshold scales with the set-cover universe n. So threshold = 2^{Θ(L)} is **unavoidable in this framework** — no choice of m or r makes it sub-exponential in L. The obstruction is not an artifact of parameter tuning.

## Honest scope

- **Ruled out:** uniformizing *this* reduction via explicit-T construction (requires an explicit exponential general-circuit LB, unavailable).
- **Not ruled out:** a *different* logtime-uniform-AC⁰ many-one reduction to MOCSP that does not require an explicitly-constructed high-complexity witness. However, any reduction that certifies NP-hardness of a meta-computational problem must, somewhere, connect the instance to a circuit-complexity threshold, and the witness-needs-high-complexity structure is inherent to the irritability/covering approach — the only known route. Extracting a 2^{Θ(L)}-complexity function *from a poly-size set-cover instance* uniformly is itself blocked (a poly-size instance has poly(L)-size description). So the obstruction is expected to generalize, though not formally proved to.
- **Not P≠NP regardless:** MOCSP is a *restricted/oracle* variant. Even a uniform-AC⁰ NP-hardness of MOCSP leaves the **restricted→original** gap (MOCSP ≠ MCSP). It would partially close `[route-a-variant-gap]` (the first uniform-AC⁰ many-one NP-hardness of *any* meta-complexity variant) but is still necessary-but-insufficient for Route A `[murray-williams-2017]`.

## The unifying diagnosis `[witness-needs-explicit-lb]`

S1.a (sources/2026-08-21-s1a-primary-source.md) and S2 are two instances of ONE obstruction:

- **S1.a (Lupanov sampling of g, Ilango FOCS 2020):** derandomizing/uniformizing requires an explicit g carrying a **DNF lower bound** in a tight window [(1−4δ)t·n², (1+4δ)t·n²] (the lower-bound side; the upper-bound side is free/constructive). Explicit exponential DNF lower bounds *do* exist (Sipser, Andreev: 2^{Ω(input)} DNF complexity), so the obstruction there is the **tight controllable window** + the **MOCE-potential** (derandomizing the union bound requires summing over an exponential formula family = the meta-computational core `[s1-meta-vs-lowdegree]`/`[s1a-antiprox-obstruction]`).
- **S2 (irritable T, Ilango ITCS 2020):** uniformizing requires an explicit T carrying a **general-circuit lower bound** > 2^{Θ(L)}. Here explicit lower bounds are stuck at Θ(L) — **exponentially short** — so the obstruction is the missing explicit *exponential general-circuit* LB (the natural-proofs frontier).

`[witness-needs-explicit-lb]`: **across the meta-complexity AC⁰ reductions, the load-bearing non-uniformity/randomness supplies a witness object (irritable T / Lupanov g) whose existence is proved probabilistically and which carries a provable circuit lower bound. Derandomizing/uniformizing requires explicitly constructing such a witness — i.e., an explicit function with a proven circuit lower bound of the required magnitude. The non-uniformity/randomness is not a removable technicality: it is the only known way to obtain a high-complexity (lower-bound-carrying) witness, because the explicit construction of a high-complexity object IS the circuit-lower-bound problem.** This is the natural-proofs barrier re-expressed at the level of the reduction's witness object. The two instances differ in *which* lower bound is the bottleneck: DNF (where explicit exponential LBs exist, so the tight-window/derandomization is the crux) vs general circuits (where explicit LBs are stuck at linear, so the exponential-LB itself is the crux). S2 is the harder of the two — the non-uniform→uniform gap is already at the explicit-exponential-circuit-LB frontier, *before* one even reaches the full Route A (restricted→original) gap.
