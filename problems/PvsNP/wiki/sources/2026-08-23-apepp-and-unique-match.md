## Finding 1 — (Q-apepp-completeness) RESOLVED to a placement, not a lever: (A) is plausibly IN APEPP but NOT APEPP-complete `[a-plausibly-in-apepp-not-complete]`

**APEPP's structure (Korten FOCS 2021, search-summary-level, NOT PDF-line-verified):** APEPP (Abundant Polynomial Empty Pigeonhole Principle, Kleinberg-Korten-Mitropolsky-Papadimitriou 2021) has the complete problem **EMPTY** — given a circuit C: {0,1}^n → {0,1}^m with m > n, find an m-bit string OUTSIDE the range of C (exists by pigeonhole: |range| ≤ 2^n < 2^m). APEPP captures explicit constructions whose existence follows from the probabilistic method, rephrased as "bad objects can be succinctly encoded using fewer than n bits." **Constructing a hard truth table is APEPP-COMPLETE under P^NP reductions** (via Jeřábek 2004's bounded-arithmetic argument reinterpreted as a search-problem reduction + the GGM pseudorandom function generator). The derandomization implication: **E^NP contains a language of circuit complexity 2^{Ω(n)} if and only if there is a P^NP algorithm for EMPTY** — so APEPP is tied to E^NP lower bounds. Many problems are IN APEPP (reduce TO EMPTY): hard truth tables, PRGs, two-source extractors, O(log n)-Ramsey graphs, rigid matrices, high-Kolmogorov strings, hard data-structure problems.

**Applying to (A):** (A) = "explicitly construct a balanced-point function (expensive ∧ small-gap) for the S1.a lifting," whose existence follows from the Lupanov probabilistic argument (the Lupanov sampler hits B w.h.p.). So (A) is structurally an APEPP-FAMILY problem (explicit construction from a probabilistic-existence argument). `[a-plausibly-in-apepp-not-complete]`: (A) is plausibly **IN APEPP** — but **NOT APEPP-complete**. The reasoning: APEPP-completeness is established for the GENERAL "hard truth table" (maximal circuit complexity, the universal object); (A) is a SPECIFIC, RESTRICTED construction — the balanced point of two particular conditions (expensive for AND_{d-1}, small gap to OR_d) at a specific depth d, NOT "any hard function." A restricted/special-case explicit construction is, by the general principle that a special case is no harder than the general problem, plausibly STRICTLY EASIER than the universal APEPP-complete problem: solving (A) (constructing a balanced-point function for AC⁰/DNF at depth d) need not let one solve EMPTY or construct Ramsey graphs / extractors / PRGs. So (A) ∈ APEPP (plausibly) but (A) is not APEPP-hard. **This is a mildly OPTIMISTIC placement, not a lever**: if (A) is in APEPP but not complete, then (A) could be strictly easier than the hardest explicit constructions (explicit Ramsey/extractor/PRG, which are APEPP-complete or APEPP-hard) — i.e., the balanced-point function might be constructible even where the universal problem is stuck. BUT the honest caveats are sharp: (i) "(A) ∈ APEPP" is PLAUSIBLE-NOT-VERIFIED — it requires the Lupanov existence argument to take APEPP's pigeonhole/encoding form ("not-balanced ⟹ a succinct encoding"), which the search did not confirm (the Lupanov argument is a measure/probabilistic argument, not obviously an encoding argument); (ii) "not complete" is a plausibility argument (restricted ⊂ general), not a proof of strict-easier; (iii) the natural-proofs/recognizability barrier still applies to (A) regardless of its APEPP status — APEPP membership is about the EXISTENCE/complexity-class placement, not about bypassing the constructivity barrier. So the APEPP lens gives a cleaner DIFFICULTY PLACEMENT (in APEPP, plausibly not complete, plausibly easier than the hardest constructions) and connects (A) to the APEPP literature, but does NOT open a construction lever. The wiki's "open construction" framing is CONSISTENT with "in APEPP, not complete" — confirmed, not moved.

## Finding 2 — (Q-unique-match) RESOLVED to a GAP that WALKS BACK the Cycle-16 two-axis-robustness: the non-large derandomization equivalence is CLASS-LB-only; the robustness is FACE-ASYMMETRIC (two axes for mining, one for S1.a) `[unique-equiv-is-class-lb-only]` `[two-axis-robustness-face-asymmetric]`

**Dhayal-Impagliazzo's precise scope (ECCC TR19-167, search-summary-level, NOT PDF-line-verified):** a **unique property** contains EXACTLY ONE function per input length (truth tables of powers-of-2 length) — the OPPOSITE of largeness. The equivalences are: **ZUE ⊄ C ⟺ P-unique property useful against C**; **UEXP ∩ co-UEXP ⊄ C ⟺ P-unique property useful against C**; and an NP-constructivity isolation result (from a property of ARBITRARY largeness, one can sometimes isolate a unique property). So the unique/non-large derandomization equivalence is a **CLASS-LOWER-BOUND** equivalence (for unambiguous-exponential-time classes UEXP/ZUE, in the chain EXP ⊆ ... ⊆ NEXP ⊆ E^NP). It is explicitly a CLASS-LB framework, generalized to all typical circuit classes "in a black-box fashion — the generalization only depends on the assumption set."

**The gap for (A):** `[unique-equiv-is-class-lb-only]`: (A)'s balanced-point set B is NON-LARGE (the small-gap property is a negligible fraction, Cycle 7's `[lupanov-largeness-violated]`) but NOT UNIQUE — B contains MANY functions (the Lupanov sampler hits B w.h.p. under its distribution, so B is not a single-function set). And (A) is an EXPLICIT-FUNCTION construction, not a CLASS lower bound. So Dhayal-Impagliazzo's unique-properties equivalence does NOT directly match (A): it requires (a) a UNIQUE (one-function) property and (b) a CLASS-LB (UEXP/NEXP) target, while (A) is non-large-but-MULTIPLE and explicit-function. The isolation result (arbitrary-largeness → unique) requires NP-constructivity and lands at the class-LB level, not the explicit-function level.
