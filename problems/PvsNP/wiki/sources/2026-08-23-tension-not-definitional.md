# Cycle 3 (2nd loop) — the tension is empirical, not definitional; the constructivity-forcing is NEXP-specific and absent for explicit f

Cycle 2 (`sources/2026-08-23-recognizable-stronger-than-natural.md`) characterized the S1.a wall as a triple conjunction {non-(P/poly)-recognizable ∧ AC⁰-constructible explicit g ∧ tight-window} and stated that Gate 1 (non-recognizable) and constructibility are in **"near-definitional"** tension — a non-recognizable method is non-constructive (⇒ no explicit f); a constructive method is recognizable (⇒ ruled out). Cycle 3 tests whether that tension is a **real incompatibility** or an **artifact of known methods**, per Cycle 2's own next-step directive. **Finding (verified against the literature): the tension is NOT definitional.** The one theorem that would make constructivity *unavoidable* — Williams' Theorem 1.1 — forces constructivity **only for NEXP-class** lower bounds, via the **Easy Witness Lemma**, which is structurally specific to **nondeterministic** classes and is **absent** for explicit/polytime functions. The S1.a witness is an explicit (even AC⁰-constructible) function, *not* a nondeterministic class, so the constructivity-forcing does **not** reach it. `[honest-ceiling]` upheld: this **loosens** Cycle 2's "near-paradox" framing (good news — the breakthrough shape is not ruled out by the constructivity-forcing theorem) but does **not** make the breakthrough achievable (the wall is reclassified from "near-paradox" to "requires a genuinely new LB method," which is still hard).

## Why Williams' constructivity-forcing is NEXP-specific `[constructivity-forcing-nexp-specific]` `[easy-witness-mechanism]`

**Verified (Williams, "Natural Proofs vs. Derandomization," SIAM J. Comput. 2016, via the arXiv 1212.1891 summary; and the Easy Witness Lemma literature):**

- **Theorem 1.1 / 1.2 (Williams):** for "typical" non-uniform circuit classes C (AC⁰, ACC⁰, TC⁰, NC¹, NC, P/poly), **NEXP ⊄ C ⟺ a P/log n-computable (resp. P) property useful against C.** Constructivity is unavoidable for **NEXP** lower bounds.
- **The forcing runs through the Easy Witness Lemma (Theorem 3.1)**, built on **Impagliazzo-Kabanets-Wigderson (IKW 2002): NEXP ⊆ P/poly ⟹ NEXP has easy witnesses** (witnesses computable by polynomial-size circuits). The equivalence chain is: NEXP ⊄ C ⟺ NEXP has no C-witnesses ⟺ NEXP has no *oblivious* C-witnesses ⟺ a useful constructive property exists. The *whole mechanism* is the **nondeterministic-witness structure of NEXP**: if a nondeterministic class has small circuits, its witnesses ARE small circuits, which a diagonalizing algorithm can detect and exploit. **This is the defining feature of nondeterministic exponential classes** (NEXP, UEXP, NE, …) — they *have* witnesses. **Deterministic / explicit functions have no analogous witness structure**, so the easy-witness forcing has no lever there.

`[constructivity-forcing-nexp-specific]`: the constructivity-unavoidability theorem is a statement about **LBs for nondeterministic classes** (NEXP ⊄ C). It says nothing about an LB for a **single explicit function** (g ∉ size-T C, g ∈ P or g ∈ AC⁰_d). The S1.a witness is exactly the latter: a *specific explicit* g (computed by the uniform AC⁰ reduction), hard for AC⁰_{d-1}. The Easy Witness Lemma cannot be invoked — there are no nondeterministic witnesses to be "easy." So **Williams' Theorem 1.1 does not force the S1.a LB to be constructive/recognizable.** Cycle 2's leap — "constructive methods are recognizable (Williams Thm 1.1) ⇒ the S1.a witness, if constructive, is recognizable" — applied an NEXP theorem to an explicit-function setting it does not cover. The inference "explicit-f LB ⇒ recognizable" is **not** supported by Williams; it is an empirical pattern, not a theorem.

## Corroboration: the forcing stays at the nondeterministic level (and is delicate for AC⁰)

- **Chen-Williams-Yang, "Black-Box Constructive Proofs Are Unavoidable," ITCS 2023** `[cwy-2023-blackbox]`:** strengthens Williams to **black-box** (sublinear-time randomized oracle) constructivity — **NEXP ⊄ C ⟺ a coRTIME[polylog(N)]/log N-constructive useful property** (N = 2^n truth-table length). The forcing remains **NEXP**-level. Crucially **Theorem 1.6: there is NO DTIME[polylog(N)]-constructive property useful against even polynomial-size AC⁰** — *deterministic* black-box constructivity is **impossible** for AC⁰; **randomness is essential**. So for AC⁰ specifically the constructivity/recognizability axis is *delicate*: deterministic constructivity fails, and only *randomized* constructivity survives — exactly the regime where one expects the natural-proofs/recognizability question to bite hardest. (Flagged: Thm 1.6 is in the sublinear black-box framework; it bounds *black-box* deterministic constructivity, not all constructivity. Web-confirmed, not PDF-line-verified.)
- **Dhayal-Impagliazzo, "Unique Properties, Lower Bounds & Derandomization," 2020** `[dhayal-impagliazzo-2020-unique]`:** extends the easy-witness framework to **UEXP** (unambiguous exponential time) and (NP∩coNP)/poly, via **"unique properties"** (containing exactly one function per input length — the extreme anti-largeness gadget): UEXP∩co-UEXP ⊄ C ⟺ a P-unique useful property. Again the forcing is tied to **nondeterministic/unique-witness** classes — and the anti-largeness is achieved by *uniqueness* (exactly one hard function per length), not by dropping constructivity. This is directly relevant: it shows the field's known ways to evade RR's *largeness* (Williams' no-largeness; unique properties) all **retain constructivity** and live at the **nondeterministic-class** level. **No analog forces constructivity for an explicit function.**

## The recognizer must solve MCSP — so "explicit g ⇒ recognizable" is NOT automatic `[recognizer-needs-mcsp]`

A natural worry (mine, mid-cycle): if g_n is explicit/AC⁰-constructible, is the LB collection S = {(g_n, T_n)} *trivially* (P/poly)-recognizable, because "h = g_n" is checkable (compute g_n, compare)? If so, ANY explicit g trips Ilango's barrier — a wall *at explicitness itself*, stronger than Cycle 2 stated. **Verified: this worry is false, and the reason is sharp.** Ilango's (P/poly)-recognizable condition (TR20-183 §1.4, lines 565-568) requires the recognizer to **accept all elements of S AND reject ALL YES-instances of (C)-MCSP** (all *easy* functions, those with small circuits). Accepting g_n is the easy part (g_n explicit ⇒ "h = g_n" checkable); **rejecting all easy functions is the hard part** — it requires the recognizer to *compute a complement of (C)-MCSP*, i.e., to detect that h has a small circuit. That is exactly the meta-computational hard direction, **independent of g_n's explicitness**. So an explicit g does **not** automatically make S recognizable: the recognizer would need to solve MCSP-complement in P/poly, which is precisely the (conditional) collapse assumption behind Ilango's barrier — not a free consequence of g being explicit. `[recognizer-needs-mcsp]`: **the barrier is on the LB *method* yielding a P/poly separator from the easy functions, not on g being explicit.** A non-recognizable LB = a proof method whose certified collection does NOT admit such a separator; this is compatible with g being explicit, because the separator (recognizer) is the LB method's *constructive certificate*, a separate object from g.

## Net — the wall is reclassified, not removed `[wall-loosened-not-fallen]`

- **Cycle 2 over-claimed the tension as "near-definitional."** It is not. The constructivity-forcing that would make "non-recognizable ⟹ non-constructive ⟹ no explicit f" a *definitional* chain is Williams' Theorem 1.1, which is **NEXP-specific** (via the easy-witness lemma) and **does not extend to explicit functions**. For explicit f, "non-recognizable LB" and "explicit-constructible g" are **compatible in principle** — they concern *different objects* (the proof method's separator vs the function itself), and the recognizer's hard part (rejecting all easy functions) is MCSP-complement, independent of g.
- **The tension is EMPIRICAL, not logical:** every *known* explicit-f AC⁰ LB method happens to be constructive/recognizable (switching lemma → Sipser/RST; diagonalization → Williams), and every *known* non-recognizable method (counting) happens to give no explicit f. This is a gap in the known method space, not a theorem of incompatibility. `[tension-not-definitional]`
- **The wall is therefore RECLASSIFIED — loosened, not fallen.** From Cycle 2's "near-paradox (non-constructive yet explicit)" to "requires a genuinely new LB method that certifies a specific explicit function hard *without* a P/poly-checkable separator from the easy functions." That is still hard — no such method is known — but it is **not ruled out by the constructivity-forcing theorem**, because that theorem's mechanism (easy witnesses) is absent in the explicit-f regime. `[wall-loosened-not-fallen]`
- **The genuine breakthrough shape is unchanged but now certified-possible-in-principle:** an explicit (AC⁰-constructible) function g with a non-(P/poly)-recognizable tight-window AC⁰ LB — a proof that g resists size-((1−4δ)T) AC⁰_{d-1} circuits whose certified collection does not admit a P/poly separator from the easy functions. The only known obstructions to it are (a) the empirical absence of such a method and (b) the tight-window gate (Gate 2), neither of which is a theorem blocking it.

## Honest scope `[honest-ceiling]`

- **No breakthrough, no new LB, no reduction.** The wall stands. This cycle *reclassifies* the obstruction (near-paradox → requires-new-method), it does not cross it.
- **The "loosened" framing is honest, not optimistic.** Loosening a *framing* (the tension is not definitional) is not the same as loosening the *wall* (the wall is still an open empirical gap with no known crossing method). I correct Cycle 2's over-strong word "near-definitional" downward to "empirical" — a *more accurate* negative, not a positive. The breakthrough remains unsolved.
- **Verified at the theorem-relationship level, flagged at the application level.** Williams Thm 1.1, the Easy Witness Lemma (Thm 3.1) + IKW 2002, CWY 2023 (incl. Thm 1.6), and Dhayal-Impagliazzo 2020 are web-confirmed (search/arXiv-summary-level, not PDF-line-verified). The *direct* statements (constructivity unavoidable for NEXP; easy-witness mechanism is nondeterministic; deterministic black-box constructivity impossible for AC⁰) are solid. The *inference* "therefore the constructivity-forcing does not extend to explicit f" is a logical observation (the easy-witness lemma requires nondeterministic witnesses, which explicit functions lack) — sound, but the boundary case "an explicit function that is ALSO in a nondeterministic class" (e.g., g ∈ NP ∩ coNP) is not addressed here and is a possible subtlety for a later cycle.
- **The recognizer-needs-MCSP point** (`[recognizer-needs-mcsp]`) is a careful reading of Ilango's definition (the recognizer must reject ALL easy functions, not just accept g); it is a logical observation about the definition, not a new theorem. The measure subtlety (whether "P/poly" in Ilango is poly in n or poly in the truth-table length) is NOT fully pinned here — the recognizer-needs-MCSP point holds *regardless* of the measure (rejecting all easy functions = MCSP-complement is hard under either measure), so the conclusion does not depend on resolving it, but a future cycle pinning the measure exactly would further sharpen the analysis.
- **CWY Thm 1.6's bearing is flagged.** "No deterministic polylog(N)-constructive useful property against AC⁰" is in the *black-box sublinear* framework; it bounds black-box deterministic constructivity, and I cite it as corroboration that the AC⁰ constructivity axis is delicate (randomness-dependent), NOT as a direct statement about the S1.a witness's recognizability. Not over-claimed.
