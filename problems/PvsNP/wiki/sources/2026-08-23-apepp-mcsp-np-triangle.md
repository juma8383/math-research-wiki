## Finding 1 — the TRIANGLE: APEPP (search) × MCSP (decision) × natural-proofs (recognizability) are three facets of one "exhibit a hard truth table explicitly" task — KNOWN to the literature, under-synthesized by the wiki `[apepp-mcsp-np-one-triangle]`

`[apepp-mcsp-np-one-triangle]`: the three lenses the wiki treated as separate threads — APEPP (Cycle 16's `[a-is-apepp-style-construction]`), MCSP / Route A (the wiki's `[mcsp-def]` meta-complexity angle), and the natural-proofs/recognizability barrier (the S1.a third loop's `[recognizable-stronger-than-natural]`) — are the SEARCH / DECISION / PROPERTY facets of ONE task: "exhibit a hard truth table explicitly."

- **APEPP = the SEARCH facet** (Korten FOCS 2021, search-summary-level, NOT PDF-line-verified): APEPP's complete problem EMPTY (find a string outside a circuit's range) is the search problem "find a hard object"; APEPP ⊆ Σ^P_2, EMPTY ∈ FZPP^NP (random sampling + NP oracle finds an out-of-range string, since ≥half of all m-bit strings are outside). Hard-truth-table construction is APEPP-complete under P^NP (via Jeřábek 2004 + GGM). So APEPP is "the search for an explicit hard object, given a probabilistic-existence argument."
- **MCSP = the DECISION facet** (Korten): MCSP ("is this truth table's circuit complexity ≥ s?") is "a universal statistical test for randomness"; and "the property of requiring large circuits is a universal pseudorandom property — a test determining whether a string requires large circuits can be bootstrapped to break any pseudorandom generator." The search-decision duality is explicit: SMCSP (the search variant, finding a minimum circuit) can REPLACE the NP oracle in hardness amplification (Theorem 12's hardness extraction uses an SMCSP oracle), even though SMCSP is not known NP-hard.
- **Natural proofs = the RECOGNIZABILITY/PROPERTY facet**: the RR barrier is precisely "a recognizable truth-table property useful against C would break PRFs" — i.e., an efficiently-RECOGNIZABLE large-circuit property is a PRG-breaker. So the recognizability barrier (S1.a's `[recognizable-stronger-than-natural]`, Ilango: the witness must NOT be (P/poly)-recognizable) is the property-side of the same hardness: a hard object that IS efficiently recognizable IS a natural property, which RR/PRFs rule out.

The triangle is KNOWN — Korten 2021 makes the MCSP↔natural-proofs↔APEPP connections explicit (MCSP as universal randomness test; the large-circuit property as universal PRG-breaker; APEPP as the search class; the encoding principle "any string failing a pseudorandom property is efficiently compressible ⟹ smaller circuit; hence any high-circuit-complexity string MUST possess the pseudorandom properties" = the APEPP encoding/pigeonhole form).
