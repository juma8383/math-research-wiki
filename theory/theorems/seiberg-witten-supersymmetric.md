# Seiberg-Witten and Nekrasov — a solved RELATED problem

## Seiberg-Witten (1994)

For $\mathcal N=2$ supersymmetric $SU(2)$ Yang-Mills, Seiberg-Witten exactly
determined the **low-energy effective theory** via the moduli space of vacua
parametrized by a genus-1 curve (the Seiberg-Witten curve). This gives an
exact, non-perturbative description including confinement and a mass gap
(monopole condensation) in certain vacua [ym-supersymmetric].

## Nekrasov instanton counting

Nekrasov rederived the Seiberg-Witten prepotential rigorously via
**instanton partition functions** (localization on the instanton moduli
space).

## Role in the obstruction

This is a **mass-gap-like result in a DIFFERENT (supersymmetric) theory**, not
the original Clay problem (pure, non-SUSY YM). It is direction (B)
(evidence/illumination): it shows the *mechanism* by which a classically
scale-invariant gauge theory develops a gap (here: monopole condensation on
the moduli space). The 't Hooft-Mandelstam picture (confinement via monopole
condensation) is the hoped-for analog for pure YM, but without SUSY the
exact-solvability tools are unavailable. [to-verify: confirm scope is N=2
SUSY, not pure YM.]
